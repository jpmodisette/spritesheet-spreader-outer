Spritesheet Spreader-Outer

This app spreads or condenses the sprites in a spritesheet.  This is intended for use with
the spritesheet contextual-duplicating editor https://jpmodisette.github.io/conextually-duplicating-spritesheet-editor/
which needs sprites to be separated so the context doesn't pick up adjacent sprites.

This code was entirely vibe-coded with ChatGPT-5.
